# 八百万診断（アフィリエイトサイト）

費用0円で運用する、自作占いのサイトです。HTML/CSS/JavaScriptだけで動き、サーバーやデータベースは使いません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | トップページ（占いフォームと結果） |
| `privacy.html` | プライバシーポリシー・免責事項（アフィリエイトの審査で必要） |
| `js/config.js` | **アフィリエイトID・サイトURLを入れる場所** |
| `js/fortune-data.js` | **占いの文章データ**（ここを書き換えて自分の占いにする） |
| `js/images.js` | 結果に出す画像（Wikimedia Commons の画像URLとクレジット）。ない項目はオリジナルイラストになる |
| `js/fortune.js` | 占いのロジック |
| `css/style.css` | デザイン |

## 占いのしくみ

1. 生まれた日の「日干」（四柱推命で使う十干）を計算し、属性（木・火・土・金・水）と陰陽を決める
2. 属性ごとに用意した候補から、インド神話・日本神話・ギリシャ神話の神、妖怪、怪異、都市伝説、相性のいい神社を1つずつ選ぶ（生年月日で決まるので一生変わらない）
3. 「生年月日＋今日の日付」から今日の運勢を計算する（毎日変わる）

候補は `js/fortune-data.js` の `RESULTS` に属性ごとに入っています。各カテゴリへ候補を足すほど結果のバリエーションが増えます。

## 無料で公開する手順（GitHub Pages）

1. GitHubのアカウントを無料で作る
2. 新しいリポジトリ（例: `fortune`）を Public で作る
3. このフォルダのファイル（`.claude` フォルダ以外）をアップロード
4. Settings → Pages → Branch を `main` にして Save
5. 数分後、`https://ユーザー名.github.io/fortune/` で公開される
6. そのURLを `js/config.js` の `siteUrl` に入れる

（Cloudflare Pages や Netlify でも同じように無料で公開できます）

## 収益化の手順

1. サイトを公開し、記事やコンテンツをある程度充実させる
2. アフィリエイトに登録（すべて無料）
   - **もしもアフィリエイト**：初心者向け。Amazon・楽天のリンクもここ経由で作れる
   - **A8.net**：案件数が最多。占いサイト向けの電話占い・ヒーリング系も多い
   - **楽天アフィリエイト**：審査なし
   - **Amazonアソシエイト**：審査あり（180日以内に3件の売上が必要）
   - **バリューコマース**：じゃらんnetの提携先（提携には審査あり）
3. 取得したIDを `js/config.js` に入れると、ラッキーアイテムの下に商品リンクが出る
4. 神社の「周辺の宿を探す」（楽天トラベル・じゃらん）は、IDが未設定だと普通のリンク、設定するとアフィリエイトリンクに自動で切り替わる
   - 楽天トラベル → `rakutenAffiliateId`（楽天市場と共通）
   - じゃらん → `valueCommerceSid` と `valueCommercePid`

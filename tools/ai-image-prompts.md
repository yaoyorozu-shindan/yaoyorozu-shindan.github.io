# 正体の絵を ChatGPT で作るためのお願い文

## 使い方
1. ChatGPT に、下の「お願い文」を1体ずつ貼りつけて絵を作ってもらう
2. できた絵を保存して、ファイル名を「保存名」のとおりに変える
3. `img/true/` フォルダに入れる（フォルダがなければ作る）
4. Claude に「絵を入れたよ」と伝える（小さくして、サイトに登録します）

- 気に入らなければ「もっと〇〇にして」と頼み直してOK
- 文字やサインは入れないように頼んであります。入ってしまったら作り直してもらう
- ほかの正体は昔の絵画や彫刻なので、雰囲気を合わせるため「昔の絵画風」にしています
